## 🚀 Installation and Usage

### Installation

You can use either Bun or npm to install and run this project

```bash
# Using Bun
bun install

# Or using npm
npm install
```

### Running the Project

```bash
# Using Bun
bunx expo start

# Or using npm
npx expo start
```

After running, Expo will open Metro Bundler allowing you to choose how to run the application:
- Press `a` to run on Android Emulator
- Press `i` to run on iOS Simulator (requires Mac)
- Scan the QR Code with the Expo Go app on your device
