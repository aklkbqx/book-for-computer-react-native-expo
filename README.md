# 📚 BookByte

![Book for Computer Logo](https://via.placeholder.com/150)

**Book for Computer** is a cross-platform mobile application developed with React Native and Expo for computer and technology enthusiasts. Access tech knowledge anytime, anywhere.

## ✨ Key Features

- 📱 Support for both iOS and Android
- 📖 Comfortable reading experience for computer science books
- 🔖 Bookmark pages to continue reading later
- 🌙 Night mode for eye-friendly reading
- 🔍 Quick search for books and content
- 📝 Note-taking and highlighting important sections

## 🚀 Installation and Usage

### Installation

You can use either Bun or npm to install and run this project

```bash
# Using Bun
bun install

# Or using npm
npm install
```

### Running the Project

```bash
# Using Bun
bunx expo start

# Or using npm
npx expo start
```

After running, Expo will open Metro Bundler allowing you to choose how to run the application:
- Press `a` to run on Android Emulator
- Press `i` to run on iOS Simulator (requires Mac)
- Scan the QR Code with the Expo Go app on your device
